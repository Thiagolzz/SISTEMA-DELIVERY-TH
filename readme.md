# 🍔 TH Delivery — Sistema de Delivery

Sistema de delivery desenvolvido em **Python**, inspirado em aplicativos como o iFood, com o objetivo de simular o funcionamento de uma plataforma de pedidos de alimentos.

O projeto tem como finalidade aplicar conceitos de **Programação Orientada a Objetos (POO)**, aprimorar a lógica de programação e desenvolver habilidades na construção de sistemas.

## 🎯 Objetivos

- Aplicar conceitos de Programação Orientada a Objetos.
- Desenvolver um sistema organizado e modular.
- Trabalhar com classes, objetos, atributos e métodos.
- Praticar estruturas de dados e manipulação de informações.
- Desenvolver regras de negócio para um sistema de delivery.

## ⚙️ Funcionalidades planejadas

- [ ] Exibir cardápio de produtos.
- [ ] Cadastrar e organizar produtos.
- [ ] Adicionar produtos ao carrinho.
- [ ] Visualizar itens do carrinho.
- [ ] Remover produtos do carrinho.
- [ ] Calcular o valor total do pedido.
- [ ] Finalizar pedidos.
- [ ] Gerar resumo da compra.

## 🛠️ Tecnologias e conceitos

- **Python**
- **Programação Orientada a Objetos (POO)**
- Git e GitHub
